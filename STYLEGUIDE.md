# Style Guide

## Colour Palette

*The colour palette are warm and earthy tones, without being too over saturated.
It also reflects fragrance ingredients, which are often times flowers or plants.*

| Colour Name | Hex Value | Usage |
| --- | --- | --- |
| [Primary] | `#F86F6B` | Main brand colour and primary buttons. |
| [Secondary] | `#92927D` | Secondary accents and highlights. |
| [Background] | `#E6E1DF` | Main application background. |
| [Text] | `#967069` | Primary text colour. |
| [Error] | `#D3411D` | Error messages and alerts. |


## Typography

*Readily available options via Google Fonts.
Easy to read and designed for screens
Secondary fonts are subject to change.*

**Main Font Family:** `Inter`

| Level | Font Size | Description/Usage |
| --- | --- | --- |
| **Heading 1** | `32px` | Main page titles. |
| **Heading 2** | `26px` | Section headers. |
| **Body** | `16px` | Standard paragraph text. |

**Secondary fonts:** `Cormorant Upright` and `Lato`.
